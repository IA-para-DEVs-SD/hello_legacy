# Hello Legacy

Sistema clássico Python mantido para referência histórica.

## 📋 Descrição

Este é um projeto de código legado que demonstra implementações básicas em Python. Criado como parte do aprendizado no **LAB 365 - IA para DEVs**.

## 🚀 Como Executar

```bash
python hello_legacy.py
```

Ou, se estiver usando Python 3:

```bash
python3 hello_legacy.py
```

## 📦 Requisitos

- Python 3.6 ou superior

## 🎯 Funcionalidades

- Função de saudação (`greet`)
- Função de despedida (`farewell`)
- Interface de linha de comando simples

├── hello_legacy.py    # Arquivo principal do programa
└── README.md          # Este arquivo
